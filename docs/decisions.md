# Journal des décisions

Une ligne par décision, la plus récente en bas. On ne réécrit pas l'histoire : une décision annulée garde sa ligne,
et la nouvelle dit ce qu'elle remplace. Les décisions d'avant la direction extraction (fuites façon Hades, mobile,
Vania, styles essayés) sont dans `docs/archives/decisions-avant-extraction.md`.

## État actuel (résumé, 2026-10-27)

- **Jeu PC** (clavier + souris, plein écran touche P), Phaser 4 + TypeScript + Vite, publié sur GitHub Pages.
- **Style « grand pixel »** : réaliste, sans contours, horreur crue (`docs/art.md`, maquettes validées dans
  `docs/maquettes/`). Lieux et personnages rendus hors ligne depuis des modèles 3D simples, éclairés par
  `src/dark.ts` ; vue ×2 ; aucune indication d'attaque au sol (le corps, la lumière et le son annoncent).
- **Boucle d'extraction** (`docs/extraction.md`) : refuge → nécropole ouverte (8×5 écrans) → intérieurs (crypte,
  nef, ossuaire, chapelle, cloître) → catacombes (6×4, par le puits) ; sang porté perdu à la mort, versé au bassin ;
  objets rapportés au coffre acquis pour toujours, sac limité ; battue (l'odeur du sang) aux passages obligés ;
  raccourcis permanents ; l'ombre cache ; la lumière sacrée brûle ; **le sang porté pèse** (plus lent, plus vite repéré).
- **Refuge** : le Rongé (marchand, améliorations), le coffre, le bassin ; Vesna une fois libérée (pouvoirs du Rat) ; il
  change avec la progression (bassin, feux, marques des morts, garde-robe, trophées) ; mannequin, table des cartes, rats.
- **Ennemis** : goule, arbalétrier et les 8 de la planche (Purificateur, Prêtre, Chien, Pénitent, Sonneur,
  Inquisiteur, Amas, Bourreau) ; boss des catacombes : la Matrice (la Nourrice, version B) ; l'Araignée gardée pour un
  autre boss (appelée par l'entraînement). Nécropole, premiers codés (pas encore
  placés, entraînement seulement) : les Corneilles, l'Enterré, le Gavé, la Chose du gouffre, le Crocheteur. **Tomber dans
  le gouffre tue** (l'expédition perdue, comme toute mort).
- **Morsure** : amélioration à acheter ; sans elle, un humain affaibli meurt normalement.
- **Son** : tout est généré par le code (`src/sfx.ts` les effets, `src/ambience.ts` l'ambiance et la musique), sur des bus
  ambiance / musique / effets et un général, en dB (`T.audio`, réglables au panneau d'entraînement) ; M coupe tout.
- **La carte** (touche C) : la zone dessinée d'après son plan, révélée là où le héros a vu, gardée pour toujours.
- **Combat** : griffes (combo, coup final, attaque en ruée), brume, tir, glyphe ; équilibre des ennemis ; **parade** (X ou clic
  molette) et riposte ; **coup chargé** (griffes tenues) ; **attaque dans l'ombre** sur un ennemi qui ne l'a pas remarqué
  (au guet, il ne voit que devant lui et met un temps à le reconnaître).
- **Vie et HUD** : 50 PV ; HUD « Chair » (`docs/maquettes/hud-2-chair.png`, `src/hud.ts`) : cœur qui noircit, veine de la
  brume, bourse de sang, marques des pouvoirs sur une peau clouée, cordon du gardien, veines aux bords quand la vie est
  basse ; mots en IM Fell English italique.
- **Menus** : écran titre « Le cercueil » (Continuer, Nouvelle partie, Options, Quitter ; `?play` le saute), pause
  (Échap : Reprendre, Options, Le sac, Abandonner l'expédition, Quitter vers le titre), options (Son, Commandes,
  Affichage) ; **toutes les commandes réaffectables** (`src/keys.ts`, une touche par ce qu'elle tape).
