# Dracul

Hades-like 2D jouable dans le navigateur, plus modeste que Hades. On joue un vampire : l'univers tourne autour
des vampires, pas des dieux. Le lore n'est pas décidé : noms provisoires, aucune histoire sans l'utilisateur.
Réponses et textes du jeu en français ; code et commentaires en anglais.
